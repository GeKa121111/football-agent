## ما تتضمنه اللعبة حاليًا

- تجربة عربية RTL تستهدف الموبايل أولًا.
- إدارة الوكالة والعملاء وعقود التمثيل والتواصل.
- اكتشاف المواهب وبعثات الكشافين وسجل الرصد.
- محاكاة مباريات ومواسم وتطور اللاعبين.
- سوق انتقالات وعروض وإعارات وشروط مالية.
- إدارة موظفي الوكالة وفروعها ورعاياتها وتمويلها.
- وكالات منافسة واهتمامات أندية مستقلة داخل المحاكاة.

بيانات اللاعبين والقوائم داخل اللعبة بيانات محاكاة خيالية وليست قوائم رسمية محدثة مباشرة.

## التشغيل محليًا

يتطلب Node.js 20 أو أحدث.

```bash
npm install
npm run dev
```

## الاختبارات والبناء

```bash
npm test
npx playwright install chromium firefox webkit
npm run test:e2e
npm run check
npm run build
```

## النشر

اللعبة منشورة عبر GitHub Pages بعد نجاح بوابة الاختبارات والبناء. راجع [تعليمات النشر](docs/DEPLOYMENT.md) وحالة أحدث تشغيل في تبويب Actions.

## بنية المشروع

- `src/core/`: الحفظ والحالة والقواعد العامة.
- `src/data/`: بيانات العالم الثابتة.
- `src/engines/`: محركات المحاكاة والانتقالات والوكالة.
- `src/ui/` و`src/styles/`: الواجهة والهوية البصرية.
- `tests/`: اختبارات الوحدة والتكامل والمتصفح.
- `docs/`: خارطة الطريق وقرارات التصميم وسجلات القبول.
