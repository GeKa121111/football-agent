# Football Agent

لعبة محاكاة لإدارة وكالة لاعبي كرة القدم. تبدأ كوكيل صغير، تكتشف المواهب، تتعاقد مع اللاعبين، تفاوض الأندية، وتبني وكالة تنافس على مستوى العالم.

> حالة العمل: تم دمج واجهة المرحلة الثانية في `main`. يجري استكمال مراجعة التفاعل والحفظ وتجربة الموبايل قبل اعتماد المرحلة نهائيًا.

## الرؤية

- تجربة عربية RTL ومصممة للموبايل أولًا.
- بطاقات لاعبين مرسومة بأسلوب شبه واقعي، بهوية داكنة ولمسات بنفسجية.
- أنيميشن خفيف وسلس للشخصيات والبطاقات والأحداث.
- محاكاة مستقلة عن واجهة العرض: قرارات الوكلاء والأندية واللاعبين لا تعتمد على الشاشة.
- عالم كرة قدم يتطور عبر المواسم، مع انتقالات وعقود ومنافسين وأحداث.

## التقنية

- HTML5 + CSS3.
- JavaScript ES Modules بدون إطار واجهات ثقيل.
- Vite للتطوير والبناء.
- اختبارات Node.js المدمجة عبر `node:test`.
- حفظ محلي بإصدار Schema واضح وقابل للترحيل مستقبلًا.

## التشغيل محليًا

يتطلب Node.js 20 أو أحدث.

```bash
npm install
npm run dev
```

## الاختبارات والبناء

## خارطة الطريق

الخطة المعتمدة للإصدار الكامل تتكون من 14 مرحلة، مع معايير قبول واضحة لكل مرحلة. المرحلة الأولى مقبولة كأساس تقني أولي، والمرحلة الثانية قيد التنفيذ. راجع [خارطة الطريق التفصيلية وحالة المراحل](docs/ROADMAP-14-PHASES.md).

1. تأسيس المحرك والبنية الأساسية.
2. الواجهة وتجربة المستخدم.
3. شخصيات اللاعبين والرسوم المتحركة.
4. قاعدة بيانات عالم كرة القدم.
5. التقويم والأحداث ودورة اللعب.
6. الكشافون واكتشاف المواهب.
7. العملاء والتعاقد والتمثيل.
8. سوق الانتقالات والتفاوض.
9. المباريات وتطور اللاعبين.
10. إدارة الوكالة وتطويرها.
11. الاقتصاد والتمويل والاستثمار.
12. الذكاء الاصطناعي والعالم الحي.
13. الإعلام والإنجازات والتجربة القصصية.
14. الاختبارات النهائية والإطلاق 1.0.

## حالة النسخة الحالية وحدودها

واجهة المرحلة الثانية مدمجة في `main`، وتحتوي على خمس شاشات عربية ونماذج لاعبين وسوق توضيحي. بيانات اللاعبين وفرص الانتقالات ورسوم الشخصيات الحالية تجريبية وليست قاعدة بيانات فعلية أو عروضًا حقيقية. لا توجد بعد محاكاة فعلية للكشافين أو العقود أو التفاوض؛ هذه الأنظمة لها مراحل مستقلة في الخطة. لا تُعلن المرحلة الثانية مكتملة قبل نجاح الاختبارات ومراجعة العرض الفعلي على الموبايل والكمبيوتر.

## مبادئ التطوير

1. كل كيان له ID ثابت، ولا نعتمد على الاسم كمفتاح.
2. محركات المحاكاة مستقلة عن واجهة المستخدم.
3. أي عملية مالية أو انتقال تمر عبر قواعد تحقق مركزية.
4. الحفظ له إصدار واختبارات، ولا نمسح ملفًا تالفًا تلقائيًا.
5. لا نضيف أنظمة ضخمة قبل اختبار دورة اللعب الأساسية.
6. الأداء على الموبايل معيار أساسي في كل مرحلة.
