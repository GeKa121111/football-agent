# Football Agent

لعبة محاكاة لإدارة وكالة لاعبي كرة القدم. تبدأ كوكيل صغير، تكتشف المواهب، تتعاقد مع اللاعبين، تفاوض الأندية، وتبني وكالة تنافس على مستوى العالم.

> حالة العمل: المراحل 1–4 مكتملة. المرحلة الخامسة قيد التنفيذ: محرك تقويم وأحداث ورسائل ومهام مع ترحيل آمن للحفظ.

## الرؤية

- تجربة عربية RTL ومصممة للموبايل أولًا.
- بطاقات لاعبين مرسومة بأسلوب شبه واقعي، بهوية داكنة ولمسات بنفسجية.
- أنيميشن خفيف وسلس للشخصيات والبطاقات والأحداث.
- محاكاة مستقلة عن واجهة العرض: قرارات الوكلاء والأندية واللاعبين لا تعتمد على الشاشة.
- عالم كرة قدم يتطور عبر المواسم، مع انتقالات وعقود ومنافسين وأحداث.

## التقنية

- HTML5 + CSS3.
- JavaScript ES Modules بدون إطار واجهات ثقيل.
- Vite للتطوير والبناء.
- اختبارات Node.js المدمجة عبر `node:test`، واختبارات متصفح Playwright/Chromium.
- حفظ محلي بإصدار Schema واضح وقابل للترحيل مستقبلًا.

## التشغيل محليًا


## المرحلة الثالثة

تم إنشاء نظام رسوم SVG أصلي لشخصيات اللاعبين مع تنويعات للوجه والشعر واللحية والطقم، وحركة خفيفة تراعي إعداد تقليل الحركة. اجتازت المرحلة 14 اختبار وحدة و12 اختبار متصفح. راجع [سجل قبول المرحلة الثالثة](docs/PHASE-3-PLAYER-ART.md).

## المرحلة الرابعة

تم إنشاء قاعدة بيانات تأسيسية مترابطة تضم 8 دول و8 دوريات و10 مسابقات و16 ناديًا و16 ملف لاعب خياليًا. ترتبط الأندية بالدوريات والدول، واللاعبون بالأندية والجنسيات، وتُفحص العلاقات والمعرفات والقيم عبر اختبارات مستقلة. واجهتا اللاعبين والكشافين تقرآن الملفات من قاعدة العالم بدل بيانات العرض المنفصلة. راجع [سجل قبول المرحلة الرابعة](docs/PHASE-4-WORLD-DATABASE.md).


## المرحلة الخامسة — التقويم والأحداث ودورة اللعب

بدأ تنفيذ المحرك المستقل للتقويم: تقدم يومي وأسبوعي، افتتاح الموسم في 1 يوليو، إحاطة أسبوعية، تقرير شهري، رسائل وارد ومهام قابلة للإنجاز والحفظ. تمت إضافة ترحيل آمن من حفظ الإصدار 1 إلى الإصدار 2 دون فقد تقدم الوكالة أو الكتابة فوق الملف عند القراءة فقط. المرحلة ما زالت قيد التنفيذ؛ لا توجد بعد جداول مباريات حقيقية أو دورة موسم كاملة. التفاصيل ومعايير الاعتماد في [سجل المرحلة الخامسة](docs/PHASE-5-CAREER-CALENDAR.md).

## حالة النسخة الحالية وحدودها

واجهة اللعبة تعرض خمس شاشات عربية وشبكة 18 قسمًا، مع بحث وفلاتر ونوافذ تفاصيل وحفظ قائمة متابعة. قاعدة العالم الحالية عينة تأسيسية فقط: أسماء الأندية والدوريات مرجعية، أما جميع ملفات اللاعبين فهي خيالية ولا تمثل قوائم رسمية. أعداد الأندية والمشاركين محدودة ولا يوجد تحديث مباشر من مزود بيانات. فرص الانتقالات المعروضة توضيحية، ولم تُفعّل بعد محاكاة فعلية للكشافين أو العقود أو التفاوض.

## مبادئ التطوير

1. كل كيان له ID ثابت، ولا نعتمد على الاسم كمفتاح.
2. محركات المحاكاة مستقلة عن واجهة المستخدم.
3. أي عملية مالية أو انتقال تمر عبر قواعد تحقق مركزية.
4. الحفظ له إصدار واختبارات، ولا نمسح ملفًا تالفًا تلقائيًا.
5. لا نضيف أنظمة ضخمة قبل اختبار دورة اللعب الأساسية.
6. الأداء على الموبايل معيار أساسي في كل مرحلة.


## تقويم دورة الوكالة السنوية

تبدأ المسيرة بسجل افتتاح الموسم، ثم تتكرر نقاط التخطيط في 15 أغسطس و15 يناير و15 يونيو، ويُسجل ختام الموسم في 30 يونيو. تعرض لوحة المسيرة المواعيد القادمة ويمكن فتح معاينة تمتد 365 يومًا. هذه مواعيد تنظيمية داخل المحاكاة وليست جداول مسابقات أو انتقالات رسمية.


### أرشيف مهام المرحلة الخامسة

يمكن فتح سجل المهام من لوحة المسيرة لمراجعة المهام المفتوحة والمتأخرة والمكتملة، والبحث في تفاصيلها أو تصفيتها حسب الحالة. يعرض السجل ما إذا كان الإنجاز في الموعد أو متأخرًا. لا توجد مكافآت مالية للمهام حتى تُبنى أنظمة الاقتصاد وإدارة الوكالة.


### سلامة سجل المهام

لا يحذف محرك التقويم المهام المفتوحة أو المتأخرة عند تقليم السجل. لا يُنشأ تكليف دوري آخر من التصنيف نفسه ما دام تكليف سابق قابلًا للإجراء، بينما تظل الأحداث الأسبوعية والشهرية مسجلة. يقتصر حد الاحتفاظ (60 سجلًا) على المهام المكتملة الأقدم، ويُختار ما يبقى حسب تاريخ الإنجاز.


### اتساق حفظ التقويم

يتحقق مخطط الحفظ من تسلسل تواريخ المهام المفتوحة والمتأخرة والمكتملة، ومن تطابق تاريخ رسالة الوارد مع الحدث المرتبط بها. الحفظ غير المتسق يُرفض دون تصحيح تلقائي أو استبدال صامت، مع بقاء إصدار الحفظ v2 دون تغيير.


### أرشيف صندوق الوارد

يعرض صندوق الوارد جميع الرسائل المحتفظ بها، مع بحث في العنوان والمحتوى والتاريخ ومعرف الحدث، وتصفية للمقروء وغير المقروء. يمكن تحديث حالة القراءة من داخل الأرشيف دون إغلاقه. عند إنجاز مهمة يُضاف إشعار غير مقروء مرتبط بحدث الإنجاز، مع منع إنشاء إشعار مكرر عند إعادة الإجراء. تعمل الوظائف فوق الحفظ v2 الحالي ولا تضيف حقولًا أو ترحيلًا جديدًا.

### سجل الأحداث

يعرض أرشيف الأحداث الأنواع التقويمية الحالية بتسميات عربية، ويظهر أولوية كل حدث. البحث يدعم عنوان الحدث ووصفه وتاريخه ونوعه المترجم وأولويته، مع بقاء الأنواع المستقبلية قابلة للتصفية دون عرض أكوادها الداخلية للمستخدم.
