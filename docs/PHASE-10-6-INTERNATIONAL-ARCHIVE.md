# Football Agent — المرحلة 10.6: الأرشيف الدولي والحفظ متعدد المواسم

**الحالة:** قيد المراجعة في PR #66 على فرع `phase-10-6-international-archive-main`.
**القاعدة:** 10.6 مبنية فوق 10.5، ولا تُدمج قبل اعتماد PR #65.

## الهدف

الاحتفاظ بتاريخ البطولات الدولية بعد انتهاء الموسم، مع البطل والنتائج وجداول المجموعات والجوائز الفردية، وحماية ملفات الحفظ v8 من التلف أو التكرار.

## ما تم تنفيذه

- [x] إنشاء سجل أرشيف مستقل لكل بطولة مكتملة، مع البطل والتاريخ والمنتخبات والنتائج.
- [x] حفظ ترتيب المجموعات النهائي.
- [x] استخراج جوائز الهداف والأكثر صناعة وأفضل لاعب بقواعد ترتيب وكسر تعادل حتمية.
- [x] ربط نسخة الأرشيف بالبطولة النشطة، ومنع إنشاء النسخة نفسها مرتين عند إعادة معالجة يوم المسيرة.
- [x] إضافة حد أقصى للأرشيفات والنسخ الموسمية النشطة حتى لا ينمو ملف الحفظ بلا حدود.
- [x] إضافة تحقق بنيوي لقوائم المنتخبات والمباريات والنتائج والإحصائيات والأرشيف والجوائز.
- [x] ربط التحقق بـ `isValidSave` دون تغيير `SAVE_VERSION = 8`.
- [x] الحفاظ على توافق ملفات v8 القديمة التي لا تحتوي على حقول البطولات أو الأرشيف.
- [x] قبول حفظ 10.5 الذي اكتملت فيه بطولة قبل إنشاء الأرشيف، حتى يتمكن أول تحديث يومي من ملء الأرشيف لاحقًا.
- [x] إظهار أرشيف الأبطال والجوائز داخل لوحة البطولات.
- [x] إظهار إحصائيات اللاعب الدولية من الأرشيف حتى بعد تقليم لقطات المواسم القديمة.

## اختبارات مطلوبة قبل الاعتماد

- [x] اكتمال بطولات قارية وإنشاء الأبطال والجوائز والأرشيف مرة واحدة.
- [x] اختبار سلامة سجلات الأرشيف ومنع تكرارها.
- [x] قبول ملفات v8 القديمة دون امتدادات دولية.
- [x] كتابة وقراءة ملف v8 يحتوي على أرشيفات دون ترقية رقم المخطط.
- [x] رفض الأرشيف التالف أو المكرر.
- [x] اختبار مسيرة تمتد لعدة مواسم مع كأس عالم وإعادة تحميل بين المواسم.
- [ ] نجاح CI الكامل وPlaywright وفحص الصياغة والبناء واختبار الموقع المنشور.
- [ ] دمج 10.6 بعد اعتماد 10.5 ونجاح كل البوابات.

## ضوابط

- لا يتم تغيير رقم مخطط الحفظ v8؛ جميع الحقول الجديدة اختيارية ومتوافقة مع ملفات الحفظ السابقة.
- إحصائيات المنتخب تبقى منفصلة عن إحصائيات النادي.
- لا تُمنح صفقات أو انتقالات أو مكافآت مالية تلقائيًا بسبب البطولات أو الجوائز.
- قاعدة العالم الحالية محدودة بـ12 دولة خيالية في ثلاثة اتحادات؛ الأرشيف يعكس عالم المحاكاة المتاح فقط.
