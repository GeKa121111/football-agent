# Football Agent — المرحلة 10.6: الأرشيف الدولي والحفظ متعدد المواسم

**الحالة:** قيد التنفيذ على الفرع `phase-10-6-international-archive`.
**الفرع الأساسي:** `phase-10-5-tournament-integration-ui` (PR #65).
**الهدف:** حفظ التاريخ الدولي والجوائز، والتحقق من التوافق مع ملفات الحفظ v8 القديمة والجديدة.

## المنجز في التنفيذ

- [x] إنشاء أرشيف مستقل لكل بطولة مكتملة يتضمن البطل، التاريخ، الاتحادات، المنتخبات، المباريات، النتائج، جداول المجموعات، وإحصائيات اللاعبين.
- [x] استخراج جوائز الهداف والأكثر صناعة وأفضل لاعب بترتيب حتمي وعوامل كسر تعادل ثابتة.
- [x] الاحتفاظ بآخر 80 أرشيف بطولة مع إبقاء نسخ المواسم النشطة منفصلة.
- [x] ربط الأرشيف بسجل البطولة، ومنع تكرار إنشاء أرشيف عند إعادة معالجة اليوم.
- [x] إضافة تحقق بنيوي لسجلات المواسم والنتائج والتشكيلات والإحصائيات والأرشيف والجوائز.
- [x] ربط التحقق بـ `isValidSave` دون تغيير `SAVE_VERSION = 8`.
- [x] السماح لملفات v8 السابقة التي لا تحتوي `tournamentSeasons` أو `tournamentArchives` بالتحميل.
- [x] السماح لملفات 10.5 التي لديها بطولة مكتملة قبل توليد الأرشيف بتحميلها، ثم إنشاء الأرشيف بأمان في دورة يوم لاحقة.
- [x] إظهار سجل الأبطال والجوائز داخل لوحة البطولات، والاحتفاظ بإحصائيات اللاعب الدولية في ملفه من الأرشيف حتى بعد حذف لقطات المواسم القديمة.

## اختبارات الاعتماد المطلوبة

- [x] اكتمال بطولة قارية وتوليد بطل وجوائز وأرشيف وحيد.
- [x] تحقق سجلات الأرشيف والنتائج وعدم تكرارها.
- [x] الحفاظ على التوافق مع ملف v8 قديم دون امتداد البطولات.
- [x] كتابة وقراءة ملف حفظ v8 يتضمن أرشيفات دولية دون تغيير رقم المخطط.
- [x] رفض الأرشيفات التالفة أو المكررة.
- [ ] اختبار دورة متعددة المواسم تشمل قارية ثم كأس عالم ثم إعادة تحميل بينهما.
- [ ] نجاح CI الكامل وPlaywright والبناء واختبار الموقع المنشور.
- [ ] مراجعة فرق التغييرات ثم الدمج بعد نجاح جميع البوابات.

## ضوابط التوافق

- لا تتم ترقية رقم مخطط الحفظ؛ الحقول الجديدة اختيارية.
- لا تُخلط إحصائيات النادي بإحصائيات المنتخب.
- لا تُنشأ صفقات أو مكافآت أو انتقالات تلقائية بسبب الجوائز.
- الأرشيف محدود الحجم، وسجلات المواسم النشطة محدودة، لتجنب تضخم LocalStorage.
- قاعدة المنتخبات الحالية محاكاة خيالية تعكس الاتحادات والدول الموجودة داخل قاعدة العالم فقط.
