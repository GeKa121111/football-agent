# المرحلة الثانية — الهوية البصرية وتجربة الاستخدام

## ما تم بناؤه في هذا الفرع

- لوحة تحكم لوكالة كرة قدم بطابع داكن ولمسات بنفسجية/سماوية.
- قائمة تنقل لسطح المكتب وشريط تنقل سفلي للموبايل.
- شاشات الرئيسية واللاعبين والكشافين وسوق الانتقالات والوكالة.
- بطاقات لاعبين برسوم CSS توضيحية متغيرة في لون البشرة والشعر والطقم.
- البحث في قائمة اللاعبين، وتصفية المواهب حسب الدور.
- نوافذ تفاصيل اللاعب وفرص السوق.
- قائمة متابعة مؤقتة داخل الجلسة مع تغذية راجعة مرئية.
- حفظ ملف المسيرة عبر نظام الحفظ المؤسس في المرحلة الأولى.
- احترام إعدادات تقليل الحركة من نظام التشغيل.

## حدود البيانات

كل أسماء اللاعبين والأندية والقيم التي تظهر على البطاقات والسوق في المرحلة الثانية بيانات توضيحية فقط، ولا تمثل قاعدة بيانات حقيقية أو عروض انتقال فعلية. قاعدة البيانات العالمية تُبنى في المرحلة الرابعة، وأنظمة الكشافين والتعاقد والتفاوض تُبنى في المراحل الخامسة والسادسة.

## التصميم

- الأولوية للموبايل مع استجابة لسطح المكتب.
- العربية هي اللغة الافتراضية واتجاه الواجهة RTL.
- لا يعتمد رسم البطاقات الحالي على صور خارجية.
- الرسوم الحالية placeholders متجهة/مبنية بـCSS وليست صور لاعبين نهائية.
- تفاصيل الشخصيات والأصول الفنية المتقدمة والأنيميشن الخاص بها تظل ضمن المرحلة الثالثة.

## معايير قبول المرحلة

1. تعمل روابط التنقل الخمسة دون إعادة تحميل الصفحة.
2. البحث يفلتر اللاعبين بالاسم أو النادي أو المركز أو البلد.
3. مرشح الدور يعرض النتائج الصحيحة.
4. نوافذ التفاصيل تفتح وتغلق وتدعم الإغلاق بالنقر خارج النافذة.
5. يمكن حفظ ملف المسيرة دون استبدال ملف تالف أو ملف من إصدار أحدث.
6. لا تتجاوز الواجهة عرض الشاشة على أحجام الموبايل الشائعة.
7. تمر اختبارات البيانات والحفظ وفحص بناء المشروع.
