# المرحلة الثانية — الهوية البصرية وتجربة الاستخدام

<badge>مكتملة — 11 نوفمبر 2026</badge>

## ما تم بناؤه واعتماده

- شاشة رئيسية موجهة للموبايل، مستوحاة من الصورة المرجعية: ملعب، بطاقة الوكيل، رصيد وسمعة وتقدم، لوحة اليوم، زر تقدم اليوم، اختصارات، ومتجر تجريبي وشبكة 18 قسمًا.
- قائمة تنقل لسطح المكتب وشريط تنقل سفلي للموبايل، مع تمييز القسم الحالي لقارئات الشاشة.
- الشاشات الخمس: الرئيسية، اللاعبون، الكشافون، سوق الانتقالات، الوكالة.
- بطاقات لاعبين برسوم CSS توضيحية متغيرة في لون البشرة والشعر والطقم.
- بحث اللاعبين بالاسم أو النادي أو المركز أو البلد.
- بحث الكشافين وتصفية المواهب حسب الدور، مع عدد نتائج مباشر.
- حالة فارغة مفهومة عند عدم وجود نتائج وزر لإعادة ضبط البحث.
- نوافذ تفاصيل اللاعب وفرص الانتقال، مع دعم Escape والنقر خارج النافذة واستعادة التركيز.
- قائمة متابعة محفوظة في LocalStorage، مع منع الإضافة المكررة وإظهار الحالة المحفوظة.
- زر تقدم اليوم يحدّث التاريخ ورقم اليوم والأسبوع ويحفظ التقدم؛ محرك الأحداث والتقويم الكامل يظل في المرحلة الخامسة.
- احترام إعدادات تقليل الحركة من نظام التشغيل، وتصميم RTL متجاوب.

## التحقق الفعلي

- 11 اختبار وحدة ناجحًا.
- 10 اختبارات متصفح باستخدام Playwright وChromium ناجحة.
- اختبارات responsive على 1440×960 و390×844 و320×740 بكسل، دون overflow أفقي.
- اختبار التنقل بين الشاشات الخمس، بحث اللاعبين، تصفية الكشافين، حالة عدم وجود نتائج، حفظ قائمة المتابعة، النوافذ والتركيز، تقدم اليوم، وحماية ملف الحفظ التالف.
- فحص صياغة JavaScript وبناء Vite نجحا.

## حدود البيانات والوظائف

اللاعبون والأندية وفرص الانتقال المعروضة حاليًا بيانات توضيحية وليست قاعدة بيانات العالم أو عروضًا حقيقية. قاعدة البيانات الفعلية في المرحلة الرابعة، والكشافون في المرحلة السادسة، وعقود التمثيل في المرحلة السابعة، وسوق الانتقالات والتفاوض في المرحلة الثامنة. الأقسام المستقبلية في الشبكة تفتح رسالة توضح أنها قيد التطوير بدل ادعاء أنها تعمل.

## معايير القبول

1. روابط التنقل الخمسة تعمل من قائمة الكمبيوتر أو شريط الموبايل.
2. البحث يفلتر اللاعبين بالاسم أو النادي أو المركز أو البلد.
3. مرشح الدور يعرض النتائج الصحيحة، والبحث يعرض عدد النتائج.
4. حالات عدم وجود نتائج تقدم إجراءً لإعادة الضبط.
5. نوافذ التفاصيل تفتح وتغلق بلوحة المفاتيح أو بالنقر خارجها، وتحافظ على وصول التركيز.
6. قائمة المتابعة تبقى بعد إعادة تحميل الصفحة ولا تسمح بتكرار الإضافة.
7. تقدم اليوم يحدث التاريخ ويُحفظ دون استبدال ملف حفظ تالف أو أحدث.
8. لا يحدث تمرير أفقي عند 320 أو 390 أو 1440 بكسل في اختبارات Chromium.
9. تنجح اختبارات الوحدة والمتصفح وفحص الصياغة وبناء الإنتاج.
